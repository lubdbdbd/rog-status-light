ROG 状态灯 1.6.0

日常使用
程序已设置为开机启动，运行后常驻托盘。
开始菜单搜索“ROG 状态灯”，或双击“打开控制面板.cmd”。
关闭窗口后继续后台运行。托盘可暂停联动、恢复自动联动、取消提醒或退出。

灯效
空闲：保持原色和亮度，常亮。USB/2.4GHz 使用 Windows 设置；蓝牙使用此前在奥创确认的原色。
工作：Esc 到 Ins 一行呈现带渐变拖尾的海浪，波峰随呼吸起伏；其他按键原色常亮。
等待回答、等待确认、额度或频率限制：原色呼吸提醒。USB/2.4GHz 使用双脉冲呼吸；蓝牙使用键盘内置的平滑呼吸。
按钮回复会解除对应问题；使用文字或截图回复后，程序在助手继续工作时解除该提醒。
任务完成或新通知：短暂呼吸提醒后恢复。任务完成通知约持续 4 秒。
多任务同时运行时，待处理提醒优先；仍有任务运行时保持滚动。

连接与 Windows 设置
USB 和原装 Omni 2.4GHz 接收器均已接通标准逐键灯控接口。新版动效保留原色，采用连续渐变和淡入淡出。
2.4GHz 和蓝牙模式均无需连接数据线。蓝牙已接入原软件的自动联动，并采用本机实测更顺滑的快速发送方式。
USB/2.4GHz：保持 Windows 动态光效开启，将背景光控列表中的“ROG 状态灯”拖到第一位。
若仅前台生效，点击动态光效页面上方的“ROG OMNI RECEIVER”或键盘设备卡片，在该设备自己的背景光控列表中将“ROG 状态灯”设为第一位。
Windows 会按设备和 USB 接口分别保存排序，接收器更换接口后请检查该设备的排序。
未取得控制权时，托盘显示“灯控待设置”，控制面板提示具体设置位置；“灯光设置”按钮可打开 Windows 对应页面。
灯控权恢复后会自动续播，并重新发送灯光画面，无需打开程序窗口。
USB/2.4GHz 每 2 秒重发完整灯光画面和原亮度。蓝牙连接中断后会重连；工作时优先更新变化最大的数字行按键。
若灯光在一段时间未操作后熄灭，先按一下 Shift 唤醒键盘。
USB/2.4GHz 通过 Windows 标准逐键灯控接口工作；蓝牙使用本机实测的键盘灯光接口。日常蓝牙联动只临时改变灯效，不反复写入板载配置。
保留键盘原有睡眠设置；睡眠熄灯后可按键唤醒。

控制面板
“自动联动”：按任务状态切换。
“暂停联动”：保持原色常亮。
“取消提醒”：清除已记录的额度提示和短暂通知。
“退出”：恢复原色常亮并释放控制。
面板中可分别测试“常亮测试”“海浪呼吸”“呼吸提醒”；完整测试每段持续 8 秒。
“蓝牙测试”由你手动点击后开始：原色常亮 4 秒 → 原色呼吸 8 秒 → 恢复原色常亮。
蓝牙测试期间点击“停止测试”可停止并恢复。测试时请保持奥创灯光设置不变，便于观察效果。
“蓝牙海浪测试”：先原色呼吸 8 秒，再尝试 Esc 到 Ins 海浪 12 秒，结束后恢复原色常亮。
海浪测试期间不保存动画帧到板载配置，只在结束恢复常亮时提交一次配置。
蓝牙呼吸、数字行滚动、恢复常亮和快速发送的流畅度均已由本机使用者确认。
“蓝牙流畅测试”：分别播放两段约 10 秒的数字行海浪，比较流畅度，结束后恢复原色常亮。
若某种发送方式不被设备支持，程序会进入下一段，并将具体原因留在测试记录中。
“自动联动”也适用于蓝牙。关闭窗口后继续后台运行；“暂停联动”和退出会恢复原色常亮。
蓝牙专项测试均由你手动点击开始，并暂停自动联动；结束后如需联动，请点击“自动联动”。

安装与卸载
完整解压后运行“安装.cmd”。首次注册本机灯控证书可能需要 Windows 管理员确认。
“退出程序.cmd”退出后台程序。
“卸载.cmd”移除本程序、自启入口、灯控注册和本程序添加的事件配置。

恢复灯光
先按 Fn + ↑ 调亮；若无效，短按 Fn + H，再将背面开关拨到 OFF，等待 5 秒后切回连接模式。

运行数据
配置、状态和日志位于用户目录下的 .rog-status-light 文件夹。
事件桥只保存事件类型、时间和任务标识，不保存提示词或聊天正文。
